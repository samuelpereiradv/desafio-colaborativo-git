# Desafio Colaborativo — WINX

Este projeto foi desenvolvido em equipe como um desafio de remodelagem de um site. A proposta foi trabalhar em uma página já existente, reorganizar sua apresentação e, principalmente, praticar o uso do **Git e do GitHub em um desenvolvimento colaborativo**.

Mais do que construir uma página, o desafio foi uma oportunidade de conhecer melhor o controle de versões, acompanhar alterações no código e aprender a trabalhar em conjunto no mesmo projeto.

## Objetivos do projeto

- Remodelar a estrutura visual e o conteúdo de um site.
- Praticar o uso do Git para acompanhar alterações no código.
- Conhecer melhor o fluxo de colaboração com o GitHub.
- Dividir ideias, trocar conhecimentos e desenvolver em equipe.

## Sobre o site

O site apresenta a equipe WINX e reúne algumas seções para organizar as informações:

- **Início:** área de destaque com imagem de apresentação.
- **Sobre:** breve descrição do grupo e de sua proposta.
- **Integrantes:** galeria de imagens da equipe.
- **Membros da equipe:** cartões com apresentação dos participantes e links para seus perfis no GitHub. Os cartões possuem um efeito de virar ao passar o cursor.
- **Linguagens:** lista de linguagens relacionadas à área de tecnologia.

## Tecnologias utilizadas

- HTML5 — estrutura e conteúdo da página.
- CSS3 — estilos, organização visual, efeitos e animações dos cartões.
- Git — controle de versão.
- GitHub — compartilhamento e colaboração no repositório.

## Como executar

O projeto é uma página estática. Para visualizar localmente:

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

Também é possível abrir o projeto pelo VS Code e utilizar a extensão **Live Server**.
